# GBA

Juegos propios para Game Boy Advance.

| Juego | Carpeta | Descripción |
|---|---|---|
| **Pampa Salvaje** | [`pampa-salvaje/`](pampa-salvaje) | Aventura de captura de fauna autóctona recorriendo una Argentina estilizada. |

Cada juego vive en su propia carpeta. Los juegos se compilan con [Butano](https://github.com/GValiente/butano),
que se clona **una sola vez** al lado de ellos (carpeta `butano/` en la raíz de este repositorio, ignorada por Git).
